# 세종과학예술영재학교 학점 관리

1학년 2학기 14개 과목의 평가 배점표를 정리하고, 학교 이메일(`@sasa.hs.kr`)로 로그인한 학생이 자신의 성적을 입력하며, 관리자 계정이 전체 통계를 확인할 수 있는 웹 앱입니다.

## 주요 기능

- **평가 배점표** (`/subjects`) — 과목별 평가 요소, 배점, 반복 횟수, 지필/수행 여부, 100점 기준 합계를 표로 확인. 실제 배점이 아직 확정되지 않아 각 과목에 "확인 필요" 임시 항목이 들어 있으며, 관리자는 이 화면에서 직접 추가/수정/삭제할 수 있습니다.
- **로그인** (`/login`) — Google 계정으로 로그인하되 `@sasa.hs.kr` 학교 이메일만 허용됩니다.
- **내 성적 입력** (`/grades`) — 1회고사·2회고사는 100점 만점으로 입력하고 배점에 맞는 비율로 환산합니다. 점수는 엔터 또는 입력란의 포커스 이동 시 자동 저장되며, 빈칸으로 지우면 삭제됩니다. P/F 결과는 선택 즉시 저장됩니다.
- **관리자 통계** (`/admin`) — 관리자 계정(`eyirania@sasa.hs.kr`)만 접근 가능. 과목별 평균/최고/최저 점수와 등록된 학생 목록을 차트와 표로 확인.

## 예측 등급과 GPA

저장된 점수 중 만점이 알려진 항목만 사용하여 `Σ(입력 점수 × 반영비율) ÷ Σ(입력한 항목의 만점 × 반복 횟수 × 반영비율) × 100`으로 예측 원점수를 계산합니다. 반복 평가의 점수는 합산하여 입력합니다. 빈칸과 만점 미정 항목은 분자와 분모에서 모두 제외하며, 실제 0점은 포함합니다. 기존 반영 합계와 확인된 배점은 그대로 유지하고, 예측만 100점 기준으로 표시합니다. 모든 항목이 입력된 100점 배점 과목에서는 예측 원점수가 실제 반영 합계와 같습니다.

등급 기준은 A+ 89.5, A0 84.5, A- 79.5, B+ 74.5, B0 69.5, B- 64.5, C+ 59.5, C0 54.5, C- 49.5점 이상이며, 49.5점 미만은 F입니다. GPA는 각각 4.3, 4.0, 3.7, 3.3, 3.0, 2.7, 2.3, 2.0, 1.7, 0입니다. 등급 판정 전 표시용 반올림은 하지 않습니다.

학생의 예측 평균 GPA는 `Σ(과목 GPA × 이수학점) ÷ Σ이수학점`입니다. 예측할 수 있는 등급 과목만 포함하며, F는 0으로 포함하고 P/F 과목은 제외합니다. 예측할 수 있는 점수가 없으면 GPA를 0이 아닌 미입력 상태로 표시합니다. 점수를 저장하거나 지우면 예측이 다시 계산되며, 최종 성적과는 다를 수 있습니다.

관리자는 과목별 평균 예측 원점수, 그 평균에 기준을 적용한 평균등급, 학생별 과목 GPA의 평균을 각각 확인할 수 있습니다. 과목별 평균등급은 평균 GPA를 등급으로 역산한 값이 아닙니다. 학생별 이수학점 가중평균 GPA와 반영 과목 수·학점도 함께 표시합니다. 계산 결과는 기존 Netlify Database 점수에서 도출하므로 별도 저장이나 스키마 변경이 필요하지 않습니다.

## 기술 스택

- TanStack Start (React 19 + TanStack Router) + Vite 7 + Tailwind CSS 4, `/p/sahak` 경로 아래에서 서비스
- Google OAuth 직접 구현 (PKCE) + Postgres 세션. `@sasa.hs.kr`만 허용, 관리자는 `eyirania@sasa.hs.kr`
- PostgreSQL + Drizzle ORM
- Chart.js (react-chartjs-2)

## 실행 (맥미니 셀프호스팅)

배포 방법은 `deploy/DEPLOY.md` 참고. 환경 변수는 `deploy/env.example`.

```bash
pnpm install
pnpm build
pnpm migrate   # DATABASE_URL 필요
pnpm start     # 127.0.0.1:5000
```

## 데이터베이스

스키마는 `db/schema.ts`, 마이그레이션은 `netlify/database/migrations/`(폴더 이름은 옛 호환용)에 있고 `pnpm migrate`로 적용합니다. 백업은 `scripts/backup.sh`, Netlify에서 옮길 때는 `scripts/import-csv.sh`를 씁니다.
